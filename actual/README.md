# Actual Format Notes

This folder is reserved for future stable format designs.

The documents under `actual/docs/` are not the formats currently emitted by the repository tools. For the active implemented render-pack format, use `../docs/osmrpack_format.md` (`OSMRPK02`) with the top-level `osmrenderpackv2`, `osmrpackinfo`, and `osmrender-rpack` binaries.

For the active implemented route-pack format, use `../docs/OSMRTE01.md` with the top-level `osmroutepack`, `osmrteinfo`, and `rtewalkroute` binaries.
